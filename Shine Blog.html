    Find out the top 20 Hibernate interview questions & answers for fresher and experienced candidates. These Interview questions will help candidates to land hibernate jobs efficiently.

    Hibernate Interview Questions & Answers

    1. What do you mean by Hibernate?

    Hibernate is an object-relational mapping framework, which allows the developer to focus on business logic by taking care of the determination of data by itself. Java developer can write code using the object, and Hibernate can ensure of creating those object from data loaded from the database and reduction update back to the database.

    1. Tell me the usage of the configuration interface it hibernates?

    Configuration line of hibernate framework is used to assemble hibernate. Mapping documents of Hibernate are situated using this interface.

    1. What are the two types of collections in hibernate?

    The two types of collections in hibernate are:

    • Order Collection
    • Sorted Collection
    1. What is the way to get the hibernate statistics?

    We can get hibernate statistics using getStatistics() method of Session Factory class as shown:
    SessionFactory.getStatistics()

    1. Define the four ORM levels in hibernate?

    The four ORM levels in hibernate are:

    • Full Object Mapping
    • Pure Relational
    • Light Object Mapping
    • Medium Object Mapping
    1. Explain the types of mapping associations used in hibernate?

    The four types of mapping associations among entities are:

    • One-to-One Association
    • One-to-Many Association
    •  Many-to-Many Association
    • Many-to-One-Association
    1. Tell me the ways to fetch the object from the database in hibernate?

    There are the following four ways to fetch objects from the database:

    • Using Identifier
    • Using HQL
    • Using Criteria API
    • Using Standard SQL
    1. How is the primary key created by using hibernate?

    Database main key is particular in the configuration file hbm.xml. The creator can also be used to recognize how major key is being shaped in the database.

    1. Tell me the default transaction factory in hibernate?

    In hibernate 3.2, the default transaction factory is JDBCTransactionFactory.

    1. Name the different fetching strategies of hibernate?

    Fetching strategies of hibernate are:

    • Select Fetching
    • Join Fetching
    • Batch Fetching
    • Sub-select Fetching
    1. Explain the use of version property in hibernates?

    The version property is used in hibernate to identify whether an object is in passing a state or in a disconnected state.

    1. What are the three inheritance models of hibernate?

    The three inheritance models of hibernate are:

    • Table per subclass
    • Table per class hierarchy
    • Tables per concrete class
    1. What do you mean by Light Object Mapping?

    Light Object Mapping is the levels of ORM superiority in which all entities are represented as classes, and they are mapped physically.

    1. What do you mean by attribute oriented programming?

    In Attribute oriented programming, a developer can insert Metadata in the java source code to insert more implication in the code. For Java attribute, oriented programming is enabled by an engine called XDoclet.

    1. Do you think to hibernate support polymorphism?

    Yes, hibernate supports polymorphism. The queries and polymorphism associations are supported in all mapping strategies of hibernating.

    1. State the difference between managed associations and hibernate associations?

    Managed associations relay to container management purpose and are bi-directional while hibernate associations are unidirectional.

    1.  Define ORM Metadata?

    All the mapping among classes and tables, properties and columns, Java types and SQL types etc. is clear in ORM metadata.

    1. What are the various types of caches available in Hibernate?

    Hibernate provides the out-of-box caching clarification, but there are various caches, e.g. first level cache, second-level cache, and query cache. The first level cache is maintained at Session level and cannot be disabled, but the second-level cache is necessary to be configured with outer cache source like EhCache.

    1. Does hibernate session interface thread-safe in Java?

    The session object is not thread-safe in Hibernate and planned to be used with-in single thread in the submission.

    1. Define JPA?

    Java Persistence API is a Java requirement that provides convinced functionality and average to ORM tools. The javax.persistence package contains the JPA classes and interfaces.
